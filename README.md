복지관에서 사회복무요원으로 근무하며 어르신들이 디지털 환경에서 겪는 어려움을 직접 경험했습니다.

그 경험은 저에게 **기술은 단순히 기능을 구현하는 것이 아니라, 누군가의 삶을 더 편리하게 만들 수 있는 도구**라는 생각을 심어주었습니다.

이후 복지와 AI를 결합한 서비스를 직접 기획하고 개발하기 시작했고, 현재는 **AI, Cloud, Security, OutSystems**를 중심으로 실무에 가까운 프로젝트를 만들며 역량을 키우고 있습니다.

저는 단순한 CRUD 구현보다 **실제 사용자가 사용할 수 있는 서비스**를 만드는 것을 좋아하며, 데이터를 기반으로 문제를 해결하는 개발자를 목표로 성장하고 있습니다.
